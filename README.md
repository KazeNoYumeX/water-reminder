# 💧 喝水鬧鐘 (Water Reminder)

一個跨平台（Windows / macOS）的簡易喝水提醒小工具，免安裝、純前端，用瀏覽器打開 `index.html` 即可使用。

## 功能

- **每日建議飲水量計算**：輸入體重與運動量，計算每日應喝水量
  - 公式：`體重(kg) × 30 ml + 運動補水量`
  - 運動補水量：無 0 ml / 輕度 350 ml / 中度 600 ml / 高度 900 ml
- **可設定提醒區間**：開始時間 / 結束時間
- **提醒間隔**：30 分鐘 / 1 小時 / 2 小時
- **自動切分每次飲水量**：將每日總量平均分配到所有提醒次數
- **桌面通知 + 音效**：使用瀏覽器 Notification API
- **設定自動保存**：使用 localStorage 記住上次的設定

## 使用方式

### Mac

```bash
open index.html
```

或在 Finder 中雙擊 `index.html`。

### Windows

直接雙擊 `index.html`，或：

```cmd
start index.html
```

### 操作步驟

1. 輸入體重與運動量 → 自動顯示每日建議飲水量
2. 設定開始時間、結束時間、提醒間隔 → 自動顯示每次應喝量
3. 按「開始提醒」→ 首次會詢問通知權限，請選「允許」
4. **保持瀏覽器分頁開啟**，到時間就會跳出通知 + 嗶聲
5. 按「停止」可隨時中斷

## 注意事項

- **必須保持分頁開啟**：關閉分頁 / 瀏覽器後提醒會停止（符合「啟動狀態下提醒」需求）
- **Mac 建議將 Safari/Chrome 通知權限打開**：系統設定 → 通知 → 找到對應瀏覽器
- **Windows 同理**：設定 → 系統 → 通知 → 開啟瀏覽器通知
- 推薦使用 Chrome、Edge、Safari，需支援 Notification API（任何 2017 年後的瀏覽器都可）

## 範例

- 體重 60 kg、輕度運動 → 每日 60×30 + 350 = **2150 ml**
- 09:00–21:00、每 2 小時 → 7 次提醒
- 每次應喝 ≈ **307 ml**
